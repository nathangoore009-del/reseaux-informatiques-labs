# Chapitre 12 — Cloud et virtualisation

## 📖 Rappel de la théorie
Virtualisation réseau, SDN, cloud networking (VPC).

## 🧪 Lab 12.1 — Créer un réseau virtuel entre plusieurs VM
- **Objectif :** Interconnecter plusieurs machines virtuelles sur un réseau isolé.
- **Prérequis / Outils :** VirtualBox ou VMware
- **Étapes détaillées :**
  1. Créer un réseau interne (Internal Network) dans VirtualBox/VMware.
  2. Créer 2-3 VM et les connecter à ce réseau virtuel.
  3. Configurer des adresses IP statiques dans le même sous-réseau sur chaque VM.
  4. Tester la connectivité entre les VM avec `ping`.
  5. Documenter le schéma du réseau virtuel créé.

## 🧪 Lab 12.2 — Déployer un VPC sur un cloud gratuit
- **Objectif :** Créer un réseau virtuel privé chez un fournisseur cloud et documenter l'architecture.
- **Prérequis / Outils :** AWS, Azure ou GCP (offre gratuite)
- **Étapes détaillées :**
  1. Créer un compte sur le fournisseur cloud choisi.
  2. Créer un VPC (Virtual Private Cloud) avec un sous-réseau.
  3. Ajouter une instance (VM) dans ce sous-réseau.
  4. Configurer un groupe de sécurité / des règles de pare-feu pour autoriser SSH.
  5. Se connecter à l'instance depuis l'extérieur pour vérifier l'accès.
  6. Documenter l'architecture (schéma + capture d'écran de la console cloud).
